# tic-tac-toe-ai
Artificial Intelligence Tic Tac Toe Project
 پروژه بازی دوز هوشمند (Tic-Tac-Toe AI)

 1. معرفی پروژه

بازی دوز (Tic-Tac-Toe) یکی از بازی‌های فکری و دونفره است که در یک صفحه 3 در 3 انجام می‌شود. هر بازیکن دارای یک علامت مشخص شامل X یا O است و بازیکنان به صورت نوبتی خانه‌های خالی صفحه را انتخاب می‌کنند.

هدف بازی این است که هر بازیکن بتواند سه علامت مشابه را به صورت افقی، عمودی یا مورب در کنار یکدیگر قرار دهد.

هدف از این پروژه، طراحی و پیاده‌سازی یک بازی دوز با استفاده از زبان برنامه‌نویسی پایتون و مفاهیم هوش مصنوعی است. در این پروژه تلاش می‌شود عاملی هوشمند طراحی شود که بتواند وضعیت صفحه را بررسی کرده و با توجه به حرکات بازیکن، تصمیم مناسبی برای انتخاب حرکت بعدی بگیرد.

2. تعریف مسئله

مسئله اصلی پروژه، طراحی یک عامل هوشمند برای بازی دوز است.

عامل هوشمند باید بتواند وضعیت فعلی صفحه بازی را مشاهده کند، خانه‌های خالی را تشخیص دهد، حرکات احتمالی را بررسی کند و بهترین حرکت را برای رسیدن به نتیجه مطلوب انتخاب کند.

نتیجه بازی می‌تواند یکی از سه حالت زیر باشد:

- برد بازیکن X
- برد بازیکن O
- مساوی شدن بازی

در نسخه هوشمند پروژه، از الگوریتم‌های جست‌وجو و تصمیم‌گیری در هوش مصنوعی برای انتخاب حرکت مناسب استفاده خواهد شد.

3. مدل PEAS

مدل PEAS برای تعریف محیط کاری عامل هوشمند استفاده می‌شود و شامل چهار بخش است.

 P - Performance Measure (معیار عملکرد)

- افزایش احتمال برنده شدن عامل هوشمند
- جلوگیری از شکست در برابر حریف
- انتخاب بهترین حرکت ممکن
- جلوگیری از انجام حرکات غیرمجاز
- تشخیص صحیح وضعیت برد، باخت و مساوی
- کاهش زمان تصمیم‌گیری

 E - Environment (محیط)

- صفحه بازی 3 در 3
- بازیکن انسانی
- عامل هوشمند
- خانه‌های خالی صفحه
- علامت‌های X و O
- قوانین و شرایط پایان بازی

 A - Actuators (عملگرها)

- انتخاب خانه موردنظر در صفحه
- قرار دادن علامت X یا O در خانه انتخاب‌شده
- ثبت حرکت بازیکن
- اعلام نتیجه نهایی بازی

S - Sensors (حسگرها)

- دریافت وضعیت فعلی صفحه بازی
- تشخیص خانه‌های خالی
- تشخیص علامت‌های X و O
- تشخیص حرکت قبلی بازیکن
- بررسی وضعیت برد یا مساوی

 4. ویژگی‌های محیط مسئله

محیط بازی دوز بر اساس شش ویژگی اصلی محیط در هوش مصنوعی بررسی می‌شود.

| ویژگی محیط | نوع ویژگی | توضیحات |

| مشاهده‌پذیری | کاملاً قابل مشاهده (Fully Observable) | تمام وضعیت صفحه بازی و حرکات بازیکنان قابل مشاهده است. |
| قطعیت | قطعی (Deterministic) | هر حرکت نتیجه مشخصی دارد و عامل تصادفی در قوانین بازی وجود ندارد. |
| ساختار زمانی | ترتیبی (Sequential) | هر حرکت بر وضعیت و تصمیم‌های بعدی تأثیر می‌گذارد. |
| تغییرپذیری | ایستا (Static) | صفحه بازی در زمان تصمیم‌گیری عامل تغییر نمی‌کند. |
| نوع داده | گسسته (Discrete) | تعداد خانه‌ها و حرکت‌های ممکن محدود و مشخص است. |
| تعداد عامل‌ها | چندعاملی (Multi-Agent) | دو بازیکن با اهداف رقابتی در محیط حضور دارند. |

 5. معیار ارزیابی پروژه (Evaluation Metrics)

برای بررسی عملکرد عامل هوشمند، معیارهای زیر در نظر گرفته می‌شوند:

1. درصد برد (Win Rate): نسبت تعداد بازی‌های برنده‌شده به کل بازی‌ها.
2. درصد مساوی (Draw Rate): نسبت تعداد بازی‌های مساوی به کل بازی‌ها.
3. درصد باخت (Loss Rate): نسبت تعداد بازی‌های باخته‌شده به کل بازی‌ها.
4. زمان تصمیم‌گیری: مدت زمانی که عامل برای انتخاب حرکت نیاز دارد.
5. دقت تصمیم‌گیری: توانایی عامل در انتخاب حرکت مناسب و جلوگیری از شکست.

فرمول محاسبه درصد برد:

Win Rate = (Number of Wins / Total Games) × 100

برای ارزیابی بهتر، عملکرد عامل هوشمند در تعداد مشخصی از مسابقات با شرایط مختلف بررسی خواهد شد.

6. ابزارها و فناوری‌های مورد استفاده

- Python: زبان برنامه‌نویسی اصلی پروژه
- NumPy: برای مدیریت آرایه‌ها و وضعیت صفحه بازی
- Matplotlib: برای نمایش گرافیکی و ترسیم محیط بازی
- Jupyter Notebook: برای بررسی و آزمایش محیط برنامه‌نویسی
- Git: برای مدیریت نسخه‌های پروژه
- GitHub: برای ذخیره‌سازی و مدیریت مخزن پروژه

 7. الگوریتم هوش مصنوعی

در مراحل بعدی پروژه، از الگوریتم Minimax برای تصمیم‌گیری عامل هوشمند استفاده خواهد شد.

این الگوریتم با بررسی حرکت‌های احتمالی و نتایج آن‌ها، تلاش می‌کند بهترین تصمیم ممکن را انتخاب کند.

هدف استفاده از Minimax، افزایش توانایی عامل هوشمند در رقابت با بازیکن انسانی و جلوگیری از شکست است.

8. هدف نهایی پروژه

هدف نهایی، طراحی و پیاده‌سازی یک بازی دوز هوشمند است که بتواند:

- وضعیت صفحه را به درستی تشخیص دهد.
- حرکات مجاز را شناسایی کند.
- بهترین حرکت را انتخاب کند.
- از قوانین بازی پیروی کند.
- برنده و نتیجه مساوی را تشخیص دهد.
- در برابر بازیکن انسانی عملکرد مناسبی داشته باشد.
